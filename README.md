# Abyss

Мультипровайдерный ИИ-клиент для Android с агентами, памятью и фирменным
анимированным фоном. Это **Stage 1** — рабочая основа. Остальные стадии
(медиа, локальная модель, VPN, терминал/самосборка) добавляются поверх.

Имя ассистента внутри — **Abyss**. Иконка — стилизованная «чёрная дыра»
(адаптивная, с кольцом аккреции).

---

## Встроенный VPN вместо Happ (Stage 4)

Весь функционал Happ переносится из его же открытого ядра — **Xray-core**.

- **Импорт**: вставьте ссылку-подписку (скачивается и парсится) или вставьте
  ссылки вручную — поддержаны **vmess, vless, trojan, shadowsocks** (включая
  TLS/Reality, ws/grpc/tcp).
- **Серверы**: список, выбор, подключение/отключение, статус; работает через
  системный **VpnService** (туннель на весь трафик устройства), так что
  отдельный Happ не нужен.
- **Движок**: сам Xray-core — нативная Go-библиотека. Kotlin-слой (разбор
  подписок, сборка конфига, VpnService, UI) готов и собирается в обычный APK.
  Нативный движок (`libabyss_vpn.so` = Xray через gomobile + tun2socks)
  собирается **опциональным** workflow **«Build Abyss APK (with VPN engine)»**
  (или `-PwithVpn`) — см. `app/src/main/cpp/vpn/CONTRACT.md`. Без него UI
  работает, но туннель не поднимется (подпись «engine not in this APK»).

## Самообучение и локальная модель (Stage 3)

- **Рекурсивное самообучение (экран Tools → Abyss Core).** Фоновый процесс
  (WorkManager, работает с закрытым приложением) по ротации тем спрашивает
  модели с ключами «научи Abyss новому», складывает ответы в память — **не
  показывая в основном чате** — а затем эти знания тихо подмешиваются (RAG) в
  обычные диалоги. Счётчик улучшений работает как «версия знаний»
  `v1.000000 → v1.000001`. Есть бюджет (сколько вопросов за цикл) и кнопка
  «Запустить сейчас».
- **Офлайн-саморефлексия.** Движок берёт накопленные знания и дистиллирует один
  улучшенный вывод. Приоритет — **локальная модель** (работает без интернета);
  если её нет и есть сеть — через онлайн-модель.
- **Локальная uncensored-модель (llama.cpp).** Слой JNI + менеджер весов GGUF:
  в Core вставляете прямую ссылку на GGUF (HuggingFace), качаете на устройство,
  выбираете и загружаете. Рекомендация под 12 ГБ RAM — uncensored 7–8B instruct,
  квантизация Q4_K_M. Нативная часть собирается **по флагу** (чтобы обычный APK
  всегда собирался): запустите workflow **«Build Abyss APK (with local model)»**
  или локально `gradle assembleDebug -PwithLocalLlm`. Без неё приложение
  полностью работает на облачных провайдерах, локальная модель просто выключена.

## Функции чата

- Действия над сообщением (долгое нажатие): **копировать, регенерировать,
  удалить**.
- **Диалоги**: новый чат (＋) и переключение между сохранёнными (история).
- **Настройки генерации**: ползунок температуры и свой системный промпт.

## Про отступления от исходного ТЗ (и что с ними сделано)

- **«Модель впитывает ответы других ИИ и дообучается»** — настоящего обучения
  весов на телефоне не бывает (нужны серверные GPU). Реализовано максимально
  близко по смыслу: автономный сбор знаний у всех моделей + накопление в память
  + RAG + офлайн-рефлексия локальной моделью. По ощущению — «учится и растёт».
  Обучение на ответах чужих ИИ нарушает их ToS; сделано по серой зоне —
  накопление в личную память, с бюджетом.
- **«Визуал 1-в-1 как у Claude Code»** — повторена вся эстетика (тёмный
  минимализм, переливающиеся символы, голубые волны от касания, AGSL-шейдер).
  Не копируется только чужой логотип/вордмарк — это trade dress.
- **«Все кнопки из тех чатов»** — добавлены реальные функции (действия над
  сообщениями, диалоги, параметры генерации); набор будет расширяться.
- **AndroidIDE/Termux/VPN** — остаются Stage 4–5: им нужны нативные бинарники и
  отдельная ветка сборки (см. ниже).

## Медиа (Stage 2)

- **Голосовые сообщения**: микрофон в чате → запись → распознавание речи
  (**Whisper** через ваш ключ OpenAI; если его нет — через Gemini) → транскрипт
  уходит как сообщение, ассистент отвечает.
- **Камера**: кнопка камеры открывает съёмку — **Фото / Видео / «Кружочек»**
  (круглая маска, как в Telegram), переключение камер, запись со звуком.
- **Распознавание содержимого**: снятое видео/кружок/фото уходит в **Gemini**,
  который описывает «что происходит и что слышно», и ответ появляется в чате.
- Требования: для голосовых — ключ OpenAI (или Gemini); для видео/фото —
  ключ **Gemini** (он понимает аудио, видео и изображения напрямую).
  Разрешения микрофона и камеры выдаются в Хабе разрешений.

## Новое в этой версии

- **Переводчик в стиле X**: язык каждого сообщения определяется автоматически;
  если он отличается от вашего языка чтения и не отключён — сообщение
  переводится инлайн с подписью «Translated from … · Show original»
  (авто-режим), либо появляется ссылка «Translate». Отключение по конкретному
  языку. Движок — **on-device ML Kit** (без ключа, офлайн после загрузки
  модели) или **ваша LLM** (аналог Grok). Есть и отдельный экран-переводчик.
- **Калькулятор** — выражения со скобками, `^`, `%`, функции sin/cos/tan/ln/log/√,
  константы π/e, история, анимированные клавиши.
- **Заметки** — список, поиск, закрепление, цвета, редактор с анимацией.
- **Будильник** — повторы по дням, метки, вибрация, снуз, полноэкранный звонок;
  **умные правила**: пропуск воскресений, и в будни после позднего отбоя
  громкость будильника поднимается автоматически. Все правила настраиваются
  вручную (базовая громкость — ползунком).
- **Анализ активности устройства** — через Usage Access оценивает время
  последней активности/подъёма и питает умную громкость будильника.
- **Защита от мошеннических звонков** — для номеров не из контактов запускается
  проверка (прозрачные эвристики + ваш опциональный источник данных по URL с
  `{number}`) и присылается уведомление с краткой аналитикой. Звонок никогда не
  блокируется — только предупреждение.
- **Хаб разрешений** в настройках — выдать по отдельности или все рантайм-права
  разом, плюс спец-доступы (Usage Access, роль скрининга звонков, точные
  будильники, игнор энергосбережения).
- **Навигация** Chat / Tools / Settings с анимированными переходами и множеством
  плавных анимаций по всему приложению.

### Честные границы новых функций

- Единой бесплатной базы мошеннических номеров не существует, а «пробив»
  произвольных сайтов ненадёжен и спорен по ToS. Поэтому ядро проверки —
  открытые эвристики; для точных вердиктов подключите свой источник данных
  (URL с `{number}`), возвращающий текст/JSON с меткой scam/spam/fraud.
- Скрининг звонков работает только когда Abyss назначен приложением для
  скрининга (роль запрашивается в Хабе разрешений).
- Перевод офлайн требует одноразовой загрузки языковой модели ML Kit.

## Что уже работает (Stage 1)

- **Чат с несколькими провайдерами**: OpenAI, Anthropic, Gemini, OpenRouter,
  плюс слот для локальной модели. Стриминг ответов (SSE).
- **Ключи вводятся вручную** и хранятся зашифрованными (Android Keystore).
- **Агенты**: выбор конкретного (General / Coder / Researcher / Media) или
  режим **Auto** — роутер классифицирует задачу и отдаёт профильному агенту.
  Без ключа/сети Auto работает по эвристике.
- **Память/знания**: ответы и выводы хранятся в отдельной базе (Room) и
  тихо подмешиваются в запрос (RAG), не засоряя ленту чата. Колонка под
  эмбеддинги и хук под векторный поиск уже заложены.
- **Темы**: Abyss (голубой), агрессивная Crimson (чёрно-красно-белая),
  Catppuccin, Tokyo Night, Nord, Rosé Pine, Gruvbox, светлая Daylight.
  Переключатель — иконка-палитра в шапке.
- **Фон**: дрейфующие мерцающие символы + голубые волны от касания,
  на Compose Canvas, рассчитан на 120 Гц (Nothing Phone 3a).
- **Версионирование** `v1.000000` готово в сборке: номер берётся из
  `version.properties` (используется механизмом самообновления на Stage 5).

## Сборка APK без компьютера (GitHub Actions)

1. Создайте репозиторий на GitHub и загрузите в него эту папку.
2. Push в ветку `main` запустит workflow **Build Abyss APK**
   (`.github/workflows/build.yml`). Он сам скачивает Gradle, генерирует
   wrapper и собирает debug-APK — бинарников в репозитории не нужно.
3. Откройте вкладку **Actions → последний запуск → Artifacts** и скачайте
   `abyss-debug-apk`. Установите APK на телефон (разрешите установку из
   неизвестных источников).

Запустить сборку можно и вручную: Actions → Build Abyss APK → Run workflow.

## Локальная сборка (если есть Android SDK)

```bash
gradle assembleDebug          # Gradle 8.11.1
# APK: app/build/outputs/apk/debug/app-debug.apk
```

Требуется JDK 17, Gradle 8.11.1 и Android SDK (compileSdk 35). Wrapper в
репозиторий не кладётся; CI и локальная сборка используют установленный Gradle.

## Первый запуск

1. Откройте приложение → шапка → **шестерёнка** (Settings).
2. Вставьте ключ нужного провайдера, нажмите **Save**.
3. Выберите провайдера и модель по умолчанию.
4. Вернитесь в чат, при желании выберите агента или оставьте **Auto**.

### Почему 2–5 нельзя «дописать текстом» в один присест

Это не про объём кода, а про бинарники и нативную сборку, которые нельзя
сгенерировать текстом в этой среде:
- **Локальная модель** — нужен бинарник `llama.cpp` под arm64 + файл весов
  модели (гигабайты), который скачивается на устройство, а не кладётся в APK.
- **VPN (замена Happ)** — нужен нативный `libxray`/`Xray-core` (Go-бинарник под
  Android) и его JNI-обвязка; собирается отдельным пайплайном (gomobile).
- **Termux/самосборка** — нужен набор нативных пакетов Termux и `targetSdk 28`
  для запуска бинарников из каталога приложения; это отдельная ветка сборки.

Эти части подключаются как внешние артефакты (NDK/prebuilt), и я распишу для
них отдельные шаги и CI, когда дойдём. Всё, что реализуемо на Kotlin/Compose,
уже в этом едином проекте и собирается в один APK.

## Честные ограничения

- Полноценное **дообучение** мультимодальной модели на телефоне невозможно —
  вместо него память + RAG + офлайн-рефлексия (ощущается как «учится»).
- Обучение на ответах чужих ИИ нарушает их условия; рекурсивный рост сделан
  через накопление знаний в памяти, бюджет фонового сбора ограничивается.
- Терминал/самосборка (Stage 5) потребует `targetSdk 28` из-за запрета
  запуска бинарников из каталога приложения — поэтому только APK, не Google
  Play. Это ожидаемо и заложено в план.

## Структура

```

  core/
    provider/   — OpenAI/Anthropic/Gemini/OpenRouter + интерфейсы
    agent/      — агенты и роутер
    memory/     — база знаний (RAG)
    data/       — Room (история чата + память)
    keys/       — шифрованное хранилище ключей
    settings/   — DataStore настроек
    net/        — HTTP + SSE
  ui/
    chat/       — экран чата, ViewModel, палитра
    settings/   — экран настроек и ключей
    background/ — анимированный фон
    theme/      — палитры и тема
```
